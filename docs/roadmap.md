# SemiLive 项目路线图

本文只定义项目阶段、交付物和完成条件，不预先规定内部模块、类、线程或目录设计。

## Milestone 0：工程基线

- [x] C++23 与 CMake 工程骨架
- [x] 发布端、转发端和接收端占位入口
- [x] Windows 与 Linux 构建预设
- [x] 基础 CTest 冒烟测试
- [x] Windows 与 Linux CI 配置
- [x] 明确 Publisher 首版音视频模块、线程、共享时间轴和依赖设计
- [ ] 确定项目许可证
- [ ] 明确首个版本的编码格式、传输范围和量化指标

完成条件：在 Windows 和 Linux CI 中均可配置、构建并通过全部测试。

## Milestone 1：桌面视频采集与编码

- [ ] 采集 Windows 桌面视频
- [ ] 支持固定分辨率与帧率
- [ ] 编码为首个版本选定的视频格式
- [ ] 保存编码结果并使用标准工具交叉验证
- [ ] 记录帧率、码率、关键帧间隔和编码延迟
- [ ] 完成 1080p30、30 分钟稳定性验证

完成条件：标准工具可以播放输出码流，时间戳单调，无持续内存增长。

## Milestone 2：视频实时传输闭环

- [ ] 实时发送编码后的视频
- [ ] 接收端恢复编码数据
- [ ] 支持大帧分片与重组
- [ ] 检测序列不连续与不完整数据
- [ ] 接入 SemiPlayer 显示视频
- [ ] 输出码率、包速率、丢包数和播放帧率
- [ ] 使用 Wireshark 或标准播放器交叉验证

完成条件：视频可经网络连续播放 30 分钟，并可以解释基本传输统计。

## Milestone 3：Linux 视频网络链路

- [ ] 转发程序在 Ubuntu 上构建和运行
- [ ] 支持一个发布者与多个播放端
- [ ] 管理会话创建、超时与释放
- [ ] 输出每路流的实时统计
- [ ] 支持优雅退出
- [ ] 增加 Linux 自动化测试与运行时检查

完成条件：Windows 发布端可经 Linux 转发到至少两个播放端，持续运行 30 分钟无明显资源泄漏。

## Milestone 4：系统音频与音画同步

- [ ] 采集 Windows 系统音频
- [ ] 编码、发送、接收并播放音频
- [ ] 实现已经设计的统一音视频时间线和轨道映射
- [ ] 接入 SemiPlayer 音频输出与同步
- [ ] 处理静音、短暂断流和设备不可用
- [ ] 记录音视频同步差值和长期漂移

完成条件：音视频可经完整网络拓扑连续播放 30 分钟且没有明显累计漂移，短暂断流后可恢复。

## Milestone 5：弱网、延迟与故障恢复

- [ ] 注入丢包、延迟、抖动、乱序和重复包
- [ ] 统计接收抖动、迟到数据和序列间断
- [ ] 明确损坏及不完整数据的处理策略
- [ ] 测量首帧时间和端到端延迟
- [ ] 记录关键帧丢失后的恢复时间
- [ ] 建立可复现的弱网测试矩阵

完成条件：每种故障场景都有可复现结果，损坏输入不会导致程序崩溃，网络恢复后可以继续播放。

## Milestone 6：v0.1.0 发布

- [ ] Windows 发布端和接收端可执行程序
- [ ] Linux 转发端可执行程序
- [ ] 少步骤启动脚本
- [ ] Windows 与 Linux CI 全部通过
- [ ] 30 分钟稳定性报告
- [ ] 弱网与端到端延迟报告
- [ ] 60 至 90 秒演示视频
- [ ] GitHub Release 与完整使用说明

完成条件：新用户可以按照 README 复现实时音视频闭环和主要测试结果。

## 首版之后

首版完成后，根据岗位反馈只选择一个方向继续：

- RTCP、反馈与丢包恢复；
- 标准会话控制协议；
- 安防协议和设备接入；
- 更多采集设备与客户端 SDK 能力；
- 多路流压力测试与服务监控。
